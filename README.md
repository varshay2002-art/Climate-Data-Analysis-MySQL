# Climate Data Analysis using MySQL

## Project Overview
This project demonstrates SQL-based analysis of climate data using MySQL. The dataset contains climate information for three districts of Karnataka: Vijayapura, Bagalkot, and Gadag.

## Tools Used
- MySQL Workbench
- SQL
- Microsoft Excel

## SQL Concepts Used
- SELECT
- WHERE
- DISTINCT
- ORDER BY
- GROUP BY
- Aggregate Functions (COUNT, AVG, MIN, MAX)

## Analysis Performed
- District-wise record count
- Year-wise data exploration
- Climate data retrieval
- Data summarization using SQL queries

## Skills Demonstrated
- Database Creation
- Data Import
- SQL Query Writing
- Data Analysis
- Climate Data Management
